## Telegram-бот (v2.0) — правила доступа
- Управлять может только владелец. Для каждого нового пользователя программа генерирует одноразовый код из 16 символов; пользователь вводит его боту, а владелец подтверждает в программе. Только подтверждённые Telegram ID получают доступ.
- Предложения: срок жизни кода (10 мин), лимит попыток, список пользователей с кнопкой «отозвать доступ», опасные действия — всегда с подтверждением в программе.
