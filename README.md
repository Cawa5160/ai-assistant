# AI Ассистент для управления компьютером (Windows 11)

Приложение слушает команды (текстом или голосом), через **Google Gemini
(бесплатный API)** анализирует экран и выполняет действия — с умным,
но безопасным подтверждением, живым прогрессом и кнопкой аварийной
остановки. Поддерживает **несколько бесплатных ключей одновременно**
(с разных Google-аккаунтов) с автоматическим переключением при лимитах.
Это обычное приложение с окном: все функции видны сразу. Крестик **сворачивает** его
в трей, и оно продолжает работать в фоне (горячая клавиша, голос, расписание).

## Установка — один файл

Скачай **`AI_Assistant_Setup.bat`** и дважды кликни. Дальше:
1. Скрипт проверит, есть ли Python (если нет — откроет страницу загрузки)
2. Молча распакует программу в папку `AI_Assistant` рядом с собой
3. Откроется **графический установщик** (логотип, прогресс-бар) — он сам поставит зависимости.
   В конце выбираешь галочками: ярлык на рабочем столе, ярлык в меню Пуск, запуск вместе с Windows

Всё содержимое (около 20 файлов) закодировано внутри этого одного `.bat` —
скачивать по отдельности ничего не нужно.

## Как оно выглядит и как им пользоваться

**Главное окно** — слева навигация, справа страницы:

| Страница | Что там |
|---|---|
| 🏠 Главная | Поле команды (Enter — выполнить), кнопка 🎙 «Голосом», примеры-подсказки, карточки «Gemini / Голос / Локальная модель» со статусом, последние действия |
| 🕘 История | Последние 20 команд с результатом и кнопкой «↻ Повторить» |
| 📅 Расписание | Команды по дням недели и времени |
| ⚙️ Настройки | Ключи Gemini, модель, **тема** (светлая / тёмная / как в Windows), горячая клавиша, папки, язык голоса и проверка микрофона, автозапуск, создание ярлыков |
| 🩺 Проверка системы | Что установлено, а что нет и почему что-то не работает |

**Закрытие окна ≠ выход.** Крестик прячет окно, программа остаётся в трее (значок рядом с часами) —
горячая клавиша `Ctrl+Shift+A`, голосовые команды и расписание продолжают работать.
Открыть окно: двойной клик по значку в трее или повторный запуск ярлыка (второй экземпляр
не создаётся — он просто показывает окно уже работающего). Полностью выйти: кнопка
«🚪 Выйти из приложения» слева внизу или «Выход» в меню трея.

**Меню трея** (правый клик по значку): Открыть окно (оно же — двойной клик) · Быстрая команда ·
Команда голосом · Повторить последнюю · Ещё ▸ (История, Расписание, Проверка системы) · Настройки · Выход.

**Окна результата не закрываются сами**: после завершения команды журнал остаётся на экране,
пока ты не нажмёшь «Закрыть».

**Автозапуск** (Настройки → Запуск) стартует программу сразу в трее, без окна (`--background`).

## ⚠️ Важно про модель Gemini

Google периодически меняет линейку бесплатных моделей и отключает старые
(например, `gemini-2.0-flash` отключена с 1 июня 2026, `gemini-2.5-flash`
будет отключена 16 октября 2026). Сейчас в `config.py` стоит актуальная
стабильная модель `gemini-3.1-flash-lite`. Если приложение начнёт получать
ошибки от Gemini — посмотри актуальный список моделей на aistudio.google.com
и поменяй значение `"model"` в `config.py`.

## Автопилот — как ассистент теперь ориентируется на экране

Раньше ИИ по ОДНОМУ скриншоту составлял весь список кликов заранее. Но после
первого же клика экран меняется (открылось окно, появилось меню), и остальные
координаты указывали в никуда — отсюда "не понимает, куда нажимать".

Теперь работает **автопилот с обратной связью**, как у настоящих computer-use агентов:

```
скриншот  →  ИИ выбирает ОДНО действие  →  выполняем  →  проверяем, изменился ли экран
   ↑                                                                    │
   └────────────────────── новый скриншот ←──────────────────────────────┘
```

- ИИ видит результат каждого шага и может исправиться ("кликнул не туда — экран не
  изменился — попробую другой элемент")
- Координаты Gemini даёт на сетке 0–1000 — программа пересчитывает их в реальные
  пиксели твоего экрана
- Защита от застревания: остановка, если ИИ трижды повторяет одно и то же, если экран
  не реагирует на три клика подряд или если превышен лимит шагов (по умолчанию 15)
- Русский текст вводится через буфер обмена (`pyautogui.write` молча пропускает
  кириллицу — раньше "найди майнкрафт" не набиралось бы вообще)

**Подтверждения — не на каждый клик, но и не "всё без спроса":**

- Один раз перед стартом: цель, первый шаг, что будет дальше. Задачи вида "просто
  открыть сайт/браузер" стартуют сами через 3 секунды (кнопка отмены рядом)
- 🔴 Потенциально необратимые шаги (файлы, установка, удаление, опасные слова) —
  **каждый раз отдельный** вопрос "Разрешить?", без исключений
- Остановить можно кнопкой 🛑 или рывком мыши в левый верхний угол экрана
- Всё, что написано на экране (сайты, письма, чаты), ИИ считает данными, а не
  командами; любое действие вне схемы (`run_powershell` и т.п.) отбрасывается

Если у тебя установлена Ollama, простые команды сначала пробуются через неё — тогда
показывается обычный план с галочками на каждый шаг.

## Быстрый старт (без командной строки)

1. Установи Python 3.10+ с [python.org](https://www.python.org/downloads/)
   — обязательно поставь галочку **"Add python.exe to PATH"**.
2. Скачай **`AI_Assistant_Setup.bat`** и дважды кликни (см. раздел выше).
3. В открывшемся графическом установщике дождись "Готово!" и нажми
   **"🚀 Запустить сейчас"** (и, если хочешь, **"Создать ярлык"**).
4. При первом запуске приложения появится окно — попросит бесплатный
   ключ (или несколько) Gemini, с кнопкой, которая откроет нужную
   страницу в браузере.

Если у тебя уже есть исходники проекта (не через `.bat`-установщик) —
ставь зависимости вручную: `python -m pip install -r requirements.txt`,
и запускай `start.bat`.

## Несколько ключей (ротация при лимитах)

Если у тебя есть несколько Google-аккаунтов, на каждом можно получить свой
бесплатный ключ Gemini и вставить их все разом (по одному на строку) — в
мастере первого запуска или потом в трее → Настройки.

- Приложение использует первый ключ, пока тот не упрётся в лимит (HTTP 429)
- При лимите — сразу переключается на следующий свободный, без остановки
- "Уставший" ключ помечается и не трогается некоторое время
- Недействительный ключ автоматически исключается из ротации на сессию
- В Настройках: **"Проверить все ключи"** и **"Обновить статус ротации"**

## Безопасность ключей и данных

- **Ключи Gemini хранятся не в открытом файле**, а в защищённом хранилище
  Windows (Credential Manager) через библиотеку `keyring` — settings.json
  их не содержит. Если по какой-то причине защищённое хранилище недоступно,
  приложение тихо откатывается на обычный файл (и предупреждает об этом
  прямо в окне Настроек), чтобы не переставать работать
- **Пароли и приватные данные не попадают в логи**: если команда просит
  ввести пароль/PIN/код доступа, ИИ сам помечает такой шаг как приватный —
  ни в логе, ни в окне подтверждения текст не показывается (видно только
  "•••••••")

## (Опционально) Локальная модель для простых команд

1. Установи Ollama: https://ollama.com/download
2. В командной строке: `ollama pull qwen2.5:3b`

Приложение само проверяет, запущена ли Ollama, и если да — сначала пробует
обработать команду локально, без интернета. Сложные команды (нужно "видеть"
экран) автоматически уходят в Gemini. Отключается в Настройках.

## Проверка системы

В трее есть пункт **"Проверка системы"** — за секунду показывает, что не
так: какие библиотеки не установились, настроены ли ключи, запущена ли
Ollama, работает ли автозагрузка, доступно ли защищённое хранилище и есть
ли доступ на запись в папку приложения. Полезно сразу после установки,
чтобы не гадать по логам, если что-то не работает.

## Свой .exe (по желанию)

Установщик работает через Python. Если нужен один `.exe` без Python на компьютере —
запусти **`build_exe.bat`** из установленной папки: он сам поставит PyInstaller и соберёт
`dist\AI_Assistant.exe`. Настройки, история и логи `.exe` хранит **рядом с собой**
(а не во временной папке, куда PyInstaller распаковывает программу при каждом запуске —
иначе всё "слетало" бы после перезапуска). Автозагрузка для `.exe` тоже работает.

Важно: собрать `.exe` можно только на самой Windows (PyInstaller не кросс-компилирует),
поэтому сборка не проверялась разработчиком — если что-то не найдётся при запуске,
PyInstaller подскажет модуль, и его добавляют флагом `--hidden-import`.

## Голосовые команды не работают — что проверить

Раньше при любой неудаче ничего не происходило вообще. Теперь приложение говорит, в чём дело
(уведомление при нажатии «🎙 Голосом» и статус на главной). Причины по частоте:

1. **Не установлены компоненты голоса** — в приложении нажми «🔧 Починить голосовой ввод» (ставится `sounddevice` и `SpeechRecognition`, компилятор не нужен)
2. **Windows не даёт доступ к микрофону** — Параметры → Конфиденциальность → Микрофон → разрешить приложениям
3. **Нет интернета** — распознавание речи идёт через Google
4. **Тихо/неразборчиво** — говори сразу после сообщения «Слушаю…», ближе к микрофону

Проверить микрофон: Настройки → Голос → «🎙 Проверить микрофон» (или страница «Проверка системы»).
Язык выбирается там же: русский / українська / English.

## Ярлык не создался

Раньше ярлык мог не появляться по двум причинам: скрипт создания записывался в неверной
кодировке (с кириллицей он ломался), и ярлык клался в `~\Desktop` — а при включённом OneDrive
настоящий рабочий стол лежит в `OneDrive\Desktop`. Теперь путь спрашивается у самой Windows,
а после создания проверяется, что файл реально появился; при ошибке показывается причина.
Создать ярлыки можно и позже: Настройки → Запуск → «Создать ярлыки».

## Известные проблемы при установке на Windows

- **Голос** использует `sounddevice` (готовые пакеты, без компилятора). Если не встал — кнопка «Починить» в приложении; остальное работает и без голоса.
- **Windows Defender / SmartScreen** может насторожиться при первом
  запуске — это ожидаемо для любого скрипта, который управляет мышью и
  клавиатурой (pyautogui, keyboard) и не подписан цифровой подписью.
  Если не доверяешь скрипту на глаз — прочитай код, он весь в этой папке
  и ничего не отправляет никуда, кроме прямых запросов к Gemini/Ollama

## Удаление

Если решишь снести приложение — запусти **`uninstall.bat`**: он уберёт
автозагрузку, ключи из защищённого хранилища, настройки/историю/логи.
Саму папку и Python-зависимости он не трогает — их можно удалить вручную.

## Как пользоваться

- Открой главное окно (ярлык, двойной клик по значку в трее) и напиши команду — или нажми «🎙 Голосом»
- **Ctrl+Shift+A** (меняется в Настройках) — быстрая команда из любого места, даже когда окно свёрнуто
- Все остальные функции — в левом меню окна (история, расписание, настройки, проверка системы)
- Значок в трее показывает состояние: 🟢 свободен, 🟠 выполняет команду, 🔴 была ошибка

## Как выполняется команда

1. Вводишь команду в окне, по горячей клавише (быстрая команда), голосом или по расписанию
2. Если есть Ollama и команда простая — короткий план с галочками, ты подтверждаешь
3. Иначе — запрос уходит в Gemini вместе со скриншотом (ключи ротируются при лимитах),
   ты один раз подтверждаешь запуск автопилота
4. Открывается окно автопилота: живой журнал, кнопка **🛑 Остановить**, встроенный вопрос для опасных шагов
5. Итог — уведомление Windows; команда и результат попадают в историю (пароли маскируются)

## Расписание задач

В меню трея → **Расписание** можно добавить задачи вида "по будням в 09:00
— открой почту". Как это работает:
- Работает, только пока приложение запущено (это не системный планировщик
  Windows — если закрыл приложение, задачи не сработают)
- Каждая задача **всё равно проходит через обычное окно подтверждения** —
  расписание не отменяет базовое правило "ничего без подтверждения"
- Задачу можно временно выключить (⏸️) или удалить

## Безопасность

- Ничего не выполняется без хотя бы какой-то формы подтверждения — для
  файловых/системных действий это ВСЕГДА явный клик "Я понимаю риск",
  без исключений (см. "Умное подтверждение" выше)
- **План от ИИ строго проверяется валидатором** (`plan_validator.py`) до
  показа пользователю: неизвестные действия, параметры неверного типа,
  координаты клика вне экрана или NaN, слишком длинный текст, недопустимые
  клавиши, подозрительные URL (`javascript:`/`file:`/`data:` и т.п.
  блокируются) и слишком большие файлы — всё отбрасывается ДО выполнения
- `open_app`/`open_url` выполняются **без участия командной оболочки**
  (`os.startfile` / `webbrowser.open`, не `shell=True`) — так текст,
  прочитанный ИИ с экрана, не может быть истолкован как отдельная команда
- `open_app` авто-подтверждается только для явно безопасных программ
  (браузеры, блокнот, калькулятор, проводник) — для всего остального
  нужен обычный клик, а не слепое доверие
- Действия с файлами — только в разрешённых папках, с проверкой границы
  каталога (не "начинается с похожей строки", а именно внутри папки —
  `Downloads` не путается с `DownloadsEvil`), и с предупреждением ещё
  ДО подтверждения
- Команды с опасными словами (удаление, форматирование, установка ПО,
  реестр и т.п.) — это всегда 🔴 высокий риск, авто-подтверждение для
  них исключено в принципе
- **Приватность в логах**: команда пользователя и её краткое описание
  сохраняются в `action_log.txt`/`history.json` уже с замаскированными
  фрагментами, похожими на пароль/PIN/токен ("<скрыто>" вместо реального
  значения) — реальный текст по-прежнему уходит в ИИ, маскировка только
  для того, что остаётся на диске
- **Одна команда одновременно**: двойное нажатие горячей клавиши или
  совпадение с запланированной задачей не запустит два действия параллельно
- **Один экземпляр приложения**: вторая попытка запуска не создаёт дубликат
- Кнопка **🛑 Остановить** прерывает выполнение перед следующим шагом
- **Аварийный стоп на уровне библиотеки**: резко подвинь мышку в левый
  верхний угол экрана (0,0) — pyautogui немедленно прервёт любое действие

## Точность и ограничения навигации

- Клики выбираются по свежему скриншоту на каждом шаге и проверяются по изменению экрана
- Качество зависит от модели: для навигации нужна модель посильнее `lite`
  (по умолчанию `gemini-3.5-flash`, бесплатна; имя можно поменять в Настройках)
- Каждый шаг автопилота = 1 запрос к ИИ, поэтому задача из 10 шагов тратит 10 запросов
  бесплатного лимита — здесь и пригождается ротация нескольких ключей
- Это **не гарантия**: на нестандартных интерфейсах, играх, мелких элементах ИИ может
  ошибаться. Автопилот это заметит по неизменившемуся экрану и остановится, а не будет
  кликать вслепую

## Автозагрузка с Windows

В Настройках — галочка "Запускать вместе с Windows" (через реестр
`HKEY_CURRENT_USER`, без прав администратора).

## Ограничения текущей версии

- Не работает "от имени администратора" — Windows сама покажет UAC, если
  действию нужны права админа
- Проверка результата клика — грубая локальная эвристика (сравнение
  скриншотов), а не гарантия; относись к ⚠️ как к подсказке, а не к истине
  в последней инстанции
- Расписание живёт, только пока приложение запущено
- Голосовое распознавание команд требует интернет; голосовой ОТКЛИК —
  офлайн (pyttsx3)

## Структура проекта

```
main.py              — точка входа, трей, горячие клавиши, оркестрация
config.py             — настройки (settings.json) + значения по умолчанию
theme.py               — единая цветовая тема и иконка для всех окон
plan_validator.py      — проверка плана от ИИ + классификация риска шагов
privacy.py              — маскировка похожих на пароли фрагментов перед сохранением
atomic_io.py            — атомарная запись JSON (settings/history/расписание)
single_instance.py      — запрет запуска второй копии приложения
secure_store.py       — защищённое хранение ключей (Windows Credential Manager)
```

## Лимиты Gemini и автопилот
- Лимиты бесплатного уровня считаются на **проект**, а не на ключ: ключи из одного проекта не складываются. Лучше по ключу из разных аккаунтов/проектов.
- Если пишет про лимит: Настройки → «Найти доступные модели» и выбери модель с бесплатной квотой. Запросов в минуту по умолчанию 6 на ключ.
- Автопилот отправляет скриншоты в Google Gemini: не оставляй на экране пароли и личные данные. Остановка: Ctrl+Shift+S или кнопка «Стоп». Опасные шаги (файлы, установка, удаление) всегда требуют твоего разрешения.

## Сборка .exe без Python (GitHub)
Залей папку в репозиторий GitHub → вкладка Actions → «Build Windows installer» → Run workflow.
Через несколько минут в Artifacts появятся `AI_Assistant.exe` и `AI_Assistant_Setup.exe`.
Тег вида `v1.5.0` дополнительно создаёт Release со скачиваемыми файлами.


## Быстрые команды (без ИИ, не тратят лимит)
«открой блокнот», «открой блокнот и напиши …», «открой калькулятор / проводник / хром», «открой ютуб / гугл / почту / телеграм / дискорд / гитхаб»,
«найди в гугле …», «загугли …», «найди на ютубе …», «сделай скриншот», «громче», «тише», «выключи звук», «пауза», «следующий трек».
Всё остальное выполняет ИИ (автопилот).

Ещё без ИИ: «поставь таймер на 10 минут», «напомни через 5 минут …», «сколько будет 15 умножить на 7»,
«открой загрузки / документы / картинки», «покажи рабочий стол», «закрой окно».

## Режим «только смотреть»
Настройки → Управление → «👁 Режим только смотреть». ИИ отвечает на вопросы про экран, но ничего не нажимает и не печатает.
