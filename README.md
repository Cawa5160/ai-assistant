# AI Ассистент для Windows 11

Настольный ИИ-помощник: пишешь или говоришь, что сделать, а он смотрит на экран и выполняет это по шагам —
с подтверждением, живым прогрессом и кнопкой аварийной остановки. Работает на **Google Gemini (бесплатный API)**,
можно подключить несколько ключей с разных аккаунтов. Управлять можно и **с телефона через Telegram**.

> ⚠️ Программа нажимает кнопки и вводит текст на твоём компьютере. Опасные действия (файлы, удаление, установка)
> всегда требуют отдельного подтверждения. Используй на свой страх и риск; для онлайн-игр с защитой от читов и
> для любых оцениваемых тестов/экзаменов её применять не нужно.

## Установка

**Самый простой способ:** скачай `AI_Assistant_Setup.bat` и запусти. Он проверит Python, распакует программу в папку
`AI_Assistant` рядом с собой и откроет графический установщик (зависимости ставятся сами).

**Настоящий `Setup.exe` без Python:** GitHub → *Actions* → «Build Windows installer» → *Run workflow*;
готовый установщик появится в *Artifacts*.

Первый запуск: вставь ключ Gemini (бесплатно: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)).
Ключей можно несколько — программа сама переключается, когда у одного кончился лимит.

**Твои данные не потеряются при обновлении.** Настройки, ключи, токен бота, макросы, заметки и расписание лежат в
`%APPDATA%\AI_Assistant` (а не в папке программы), ключи и токен ещё и в зашифрованной резервной копии
(защита Windows DPAPI). Обновляться можно запуском нового установщика поверх.

## Что умеет

| | |
|---|---|
| **Автопилот** | «Открой калькулятор и посчитай 12×7»: смотрит на экран, делает до 3 действий за шаг, проверяет результат, останавливается при зацикливании |
| **Быстрые команды без ИИ** | Открыть программу/сайт, поиск в Google/YouTube, громкость, пауза, скриншот, окна, таймер и напоминание, калькулятор, время/дата, папки. Не тратят лимит Gemini |
| **Макросы** | Выполнил команду → «запомни как утро» → «макрос утро». Список, запуск и удаление — на странице «🧠 Макросы и заметки» |
| **Заметки** | «Запомни, что мой город Киев» — ИИ учитывает это как факт о тебе |
| **Шаблоны** | «Шаблон утро / работа / перерыв / тишина / вечер»; свои: «создай шаблон вечер: открой ютуб; громче» |
| **Буфер обмена** | «Что в буфере», «переведи / исправь / объясни / перескажи / сократи буфер» (результат сразу в буфере) |
| **Расписание** | Команды по дням и времени, с условиями: есть интернет, ты за компьютером / не за ним, запущен или нет Chrome |
| **Голос** | Кнопка 🎙, горячая клавиша, необязательное «Эй, ассистент» без кнопки; озвучка действий (офлайн) |
| **Файлы** | Кнопка «📎 Файл»: картинка → ответ на вопрос о ней; аудио → речь распознаётся и выполняется как команда |
| **Только смотреть** | ИИ отвечает про экран, но ничего не нажимает |
| **Запасные модели** | При лимите основной модели пробует другие бесплатные модели Gemini |
| **Профили приложений** | Подсказки для ИИ под конкретные программы (свои — в `profiles.json`) |

Закрытие окна сворачивает программу в трей, горячие клавиши, голос, расписание и Telegram продолжают работать.
Горячие клавиши по умолчанию: `Ctrl+Shift+A` — быстрая команда, `Ctrl+Shift+V` — голос, `Ctrl+Shift+S` — стоп.

## Telegram-бот (необязательно)

У каждого свой бот — общего «чужого» бота нет, поэтому доступ только у тебя.

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и логин (оканчивается на `bot`) → получи токен.
2. В программе: *Настройки → Telegram* → включи, вставь токен, «Сохранить настройки».
3. Напиши своему боту `/start` — он выдаст **код из 16 символов** (живёт 10 минут).
4. Введи код в программе (*Заявки на доступ*) и подтверди — только человек за компьютером может дать доступ.

Что умеет бот: любые команды текстом и **голосовыми**, **фото** с вопросом, кнопки быстрых действий (`/menu`),
`/screen`, `/screenfile`, `/status`, `/stop`, `/history`, `/notes`, `/macros`, `/windows`, `/clip`.
Все вопросы программы приходят в чат кнопками **Разрешить / Отмена**; опасные действия спрашиваются дважды.
Безопасные быстрые команды можно выполнять сразу, после задачи бот может присылать скриншот — обе настройки в *Настройки → Telegram*.
Токен храни в тайне: он даёт управление ботом. Если токен утёк — `/revoke` у BotFather и вставь новый в программу.

## Безопасность

- Каждый план от ИИ проходит проверку (допустимые действия, типы и диапазоны аргументов, клавиши, URL) и классификацию риска.
- Низкий риск (открыть сайт/известную программу, скриншот) может запускаться после короткого таймера; всё остальное — с подтверждением; файловые операции и «опасные слова» — всегда с явным разрешением.
- Пароли и ключи маскируются в логах, истории и чате; текст «чувствительного» ввода не сохраняется в макросах и заметках.
- Ключи Gemini и токен бота — в хранилище Windows (keyring/DPAPI), а не открытым текстом.
- Аварийная остановка: горячая клавиша, трей, `/stop` в Telegram, рывок мыши в левый верхний угол.
- «Эй, ассистент» слушает постоянно: звук не хранится, но каждая услышанная фраза уходит на бесплатное распознавание Google, чтобы найти ключевое слово. Выключено по умолчанию.

## Если что-то не работает

- Страница **«🩺 Проверка системы»** покажет, чего не хватает и почему.
- **Микрофон:** *Настройки → Голос → Проверить микрофон* (скажет «тихо / нормально / громко»); в Windows включи *Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям*.
- **Gemini отвечает ошибкой лимита/перегрузки:** добавь ещё ключ или подожди — программа сама попробует запасные модели.
- **Telegram: «бот уже запущен в другой копии»:** закрой лишнюю копию программы (трей → Выход).
- Логи: `%APPDATA%\AI_Assistant\action_log.txt`.

## Для разработчиков

Python 3 + Tkinter, без тяжёлых зависимостей; GUI в одном потоке (`ui_thread`), остальное в рабочих потоках.

```
main.py            запуск, трей, горячие клавиши, обработка команд
agent_loop.py      цикл «экран → действие → проверка»
ai_brain.py        запросы к Gemini, ключи, запасные модели
plan_validator.py  проверка и классификация риска планов
action_executor.py выполнение шагов (мышь, клавиши, окна)
quick_commands.py / quick_actions.py / templates.py / clipboard_tools.py / macros.py   команды без ИИ
telegram_bot.py    бот (long polling, без сторонних библиотек)
wakeword.py / voice_input.py / media_input.py          голос и вложения
scheduler.py       расписание с условиями
backup.py / app_paths.py / config.py                   данные и настройки
tools/             сборка и проверка установщика
```

Запуск из исходников: `pip install -r requirements.txt` → `python main.py`.
Сборка `.exe`: `build_exe.bat` или workflow GitHub Actions. История изменений — в `CHANGELOG.md`, планы — в `ROADMAP.md`.
